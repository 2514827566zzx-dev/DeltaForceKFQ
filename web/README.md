# 三角洲口风琴自动演奏器 · macOS 输入测试版

本版本的“开始演奏”通过本地后台发送真实键盘、鼠标操作，网页只负责选曲和控制。原网页合成音播放已移除。最终目标仍是 Windows EXE；macOS 版本用于先验收输入映射。

## 启动与授权

1. 双击 [启动网页.command](./启动网页.command)，保持启动窗口运行。
2. 在系统设置 → 隐私与安全 → 设备控制和数据访问中添加并开启 [口风琴输入助手.app](./native/口风琴输入助手.app)；旧版 macOS 的对应入口可能名为“辅助功能”。这是本项目内生成的输入进程；不需要给网页或其他无关程序新增权限。
3. 用 Chrome 打开终端显示的本地地址，默认 `http://127.0.0.1:8765`。已有旧版页面请刷新。
4. 选中曲目，点击“开始演奏”，在 3 秒准备时间内切到接收窗口，把鼠标放在不会误触控件的区域。
5. 也可先切到接收窗口，再按 Shift+F2 开始或暂停，Shift+F9 随时停止。Shift+F1 收起/展开挂件仍需要控制页面或挂件拥有焦点。

若权限未开启，程序会报出系统权限提示，不会用合成音或网页假按键冒充演奏。运行需要 Python 3。随包的输入助手为 Apple Silicon Mac 编译；修改 Swift 源码后通过 `sh native/build-mac.sh` 重编译，需要 Xcode Command Line Tools。重新编译可能需要重新允许辅助功能权限。

## 保留的界面

保留原型黑黄主面板、切角按钮、曲库搜索/收藏/分页、六档速度、MIDI/TXT 导入，以及独立画中画挂件。曲库和字体均在本地，内置 663 首歌曲。没有新增设置页、账号、音量控制或其他功能入口。

暂停和停止都会释放本程序按住的键鼠。拖动进度会暂停，调整后可在接收窗口按 Shift+F2 继续，避免定位时把按键送到控制页。更换接收应用或窗口标题会暂停演奏；关闭控制页、后台断开时也会释放输入。

## 键位规则

| 操作 | 映射 |
|---|---|
| C4 起的大调音阶 | Z X C V B N M , |
| 降八度 | 按住鼠标左键 |
| 升八度 | 按住鼠标右键 |
| 升半音 | 按住鼠标中键，即滚轮下按 |

左右键可以分别与中键同时按住。每个音先按鼠标修饰，再按音阶键；结束时先松开音阶键，再按相反顺序松开修饰键。滚轮下按使用中键事件，不是滚动事件。

MIDI 使用固定 C4 基准映射。只有一个八度的鼠标修饰，不能通过重复 mouse-down 伪造两次八度；超出可演奏范围的音符按整八度折叠。和弦同时起音时取最高音，相邻音之间留出释放间隙。TXT 的显式键位会保留；不可表达的双八度修饰会明确拒绝。

## 验收

在 [KeyTest 检测页](https://keytest.lalosolo.com/index.html)测试：

- [键鼠映射验收.txt](./tests/fixtures/键鼠映射验收.txt)：14 个音，覆盖八个音阶键、左右中键及组合修饰。预期键盘 14 次按下和 14 次松开；左键 2 组、右键 3 组、中键 3 组。
- [按键释放验收.txt](./tests/fixtures/按键释放验收.txt)：长音 X + 右键 + 中键，用于检查中途暂停/停止是否释放。

先确认检测页能识别输入并清空记录，再让程序演奏；检测页实际收到的系统事件才是成功依据。Python 记录桩的逻辑测试不能替代这一步。

```sh
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --test tests/*.test.mjs
```

## 结构和后续 Windows 版

- [native-player.js](./dist/native-player.js)：网页控制协议，不再合成声音。
- [input_engine.py](./input_engine.py)：音符映射、单线程定时、暂停/停止/倍速。
- [MacInput.swift](./native/MacInput.swift)：Core Graphics 系统输入、焦点检查和全局快捷键。
- [server.py](./server.py)：仅监听回环地址的本地接口；输入控制要求同源和会话令牌。

Windows 的 SendInput、原生置顶窗口和 EXE 安装包已在 [windows](../windows/) 实现，仍需 Windows 实机验收。[启动网页.bat](./启动网页.bat)仅能启动网页服务，不能让本 Mac 输入助手在 Windows 工作。

## 曲库与字体来源

663 首 MIDI 保持用户提供文件的原始内容，分享者、来源、音符数保存在 [曲库清单](./dist/assets/library.json)，来源说明见 [SOURCES.txt](./dist/assets/SOURCES.txt)。字体授权随 [fonts](./dist/assets/fonts/)保存。

收藏和个人导入保存在当前浏览器、地址和端口对应的本地存储中。请固定使用同一地址；清除网站数据会清除个人导入与收藏，但不会影响内置曲库。
